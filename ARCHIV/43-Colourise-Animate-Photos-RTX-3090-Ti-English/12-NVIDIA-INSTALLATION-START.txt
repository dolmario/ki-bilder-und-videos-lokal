NVIDIA: INSTALLATION AND STARTUP — EDITORIAL DRAFT

Reconstruction guide based on returned evidence and official documentation. No fresh installation or new model execution performed. Four reconstructed UI graphs per computer were imported and exported again; see attachment 13. Do not apply this NVIDIA procedure to AMD. As of 2026-10-05.

1. RECORD THE SOFTWARE AND MEMORY CONFIGURATION

Tested: ComfyUI Portable NVIDIA v0.38.0, commit 6b747c0, embedded Python 3.13, Torch 2.14.0+cu130. The AMD reference uses a different commit. Do not present this as a same-version hardware comparison.

4. CHECK THE EMBEDDED PYTHON

In cmd.exe, not PowerShell syntax:

cd /d C:\ComfyUI-Dolmario\ComfyUI_windows_portable

python_embeded\python.exe --version

python_embeded\python.exe -s -c "import torch; print(torch.__version__); print(torch.version.cuda); print(torch.cuda.is_available())"

This checks the runtime without loading an image model. Do not use global pip or a separate Python installation here. The CUDA number in nvidia-smi describes driver capability and need not equal the Torch package CUDA version.

5. START THE SERVER ONCE

First check that no second instance or other heavy model job is running. For the normal NVIDIA portable installation, open run_nvidia_gpu.bat and keep its console open. After a successful start, open http://127.0.0.1:8188 in the browser. Do not start another server if one is already running.

For the 3090 Ti, SETUP.md records the normal portable launch. Do not claim the 3080 Ti workaround is required here. The additional LTX path flattens a UI subgraph into API nodes using the custom ltx_api.py script; it is not a new core node.

6. GGUF ONLY FOR THE GGUF PATH

https://github.com/city96/ComfyUI-GGUF

Qwen 2.1 and Klein 4B do not require UnetLoaderGGUF. For FLUX.2 dev GGUF, the official guide provides these commands from the portable directory (Git must be available; current dependencies are not necessarily identical to the historical tested versions):

git clone https://github.com/city96/ComfyUI-GGUF ComfyUI/custom_nodes/ComfyUI-GGUF

python_embeded\python.exe -s -m pip install -r ComfyUI\custom_nodes\ComfyUI-GGUF\requirements.txt

Do not clone into an existing directory or blindly change a working installation. The test copied the node package from USB; its exact commit is not established here. gguf 0.19.0 is documented. GGUF weights belong under ComfyUI/models/unet. After installation restart an idle server and check for UnetLoaderGGUF in the node menu.

7. LOADING IS NOT EXECUTION

Attachment 11 describes the eight-node, ten-link Qwen 2.1 clothing graph. Original API JSONs in attachment 10 have no verified visual layout; do not call them finished UI files. The easier starting point is its matching file under UI-REKONSTRUIERT: import it following attachment 13, select the models and choose your own permitted input in LoadImage. The ZIP contains no input photos. Alternatively connect the nodes manually following attachment 11. Check every link and parameter. Save the workflow before running. Begin with one controlled task, then inspect content and file integrity. SaveImage writes to ComfyUI/output; the historical kolor_ prefix was also used for clothing. A filename or success status alone does not constitute acceptance.

The historical python313._pth change served the custom batch runners only. It is not a general installation step for browser workflows. Do not blindly copy paths from another computer.
