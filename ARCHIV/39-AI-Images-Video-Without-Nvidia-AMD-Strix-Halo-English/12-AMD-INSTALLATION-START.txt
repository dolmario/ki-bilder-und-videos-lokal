Why -f? AMD’s Windows repository is a file listing and also supplies the rocm dependency. Pins prevent an unnoticed switch to another Torch build when installing ComfyUI dependencies. torch.cuda returning True is the expected PyTorch API on AMD too, not NVIDIA detection. Stop on False or import errors.

Models: attachment06 maps diffusion model, matching encoder and VAE. Choose one path first. FLUX.2 Klein4B needs no GGUF custom node. Only the FLUX.2 dev GGUF path requires ComfyUI-GGUF; its historical commit is not recorded. This is not a claim of a fully frozen fresh installation.

Local launch evidence: comfy/START-COMFYUI-QWEN.cmd uses venv-qwen and8189. The valid LTX02c run is labelled No-Pin, but its complete historical launch command has not been recovered. Do not present the NVIDIA No-Pin fix as the historical AMD command. A port does not identify a model family.
