Input-to-output workflow — AMD Strix Halo / Ryzen AI Max+ 395 / EVO-X2

1. Confirm hardware, free SSD space, model licence and the exact task.
2. Install the documented ComfyUI build and only the required GGUF custom node.
3. Put each verified model in the folder listed in 06-MODELLE-UND-ORDNER.txt.
4. Start only one heavy ComfyUI/model instance. Preserve the exact start command.
5. Load the tested workflow, choose the input, model, seed and exact prompt.
6. Generate one controlled result before starting a batch.
7. Check content, faces, hands, text, alpha, crop and start/middle/end of videos.
8. Keep failed outputs and logs; API success or a decodable file is not visual approval.
9. Export only accepted results and retain prompt, seed, model, workflow and licence.

Platform note:
Two separate local ComfyUI environments on ports 8189 and 8188. The recorded local LTX runner ltx_video.py defaults to 8189; a port is not a fixed model assignment. PyTorch 2.9.1+rocm7.2.1. Run one heavy model at a time.
